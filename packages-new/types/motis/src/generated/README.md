# Generated MOTIS API contracts

Generated from the MOTIS v2.10.2 OpenAPI:

Only `types.gen.ts` and `schemas.gen.ts` are included. `services.gen.ts` is intentionally omitted because GO applications use their own HTTP clients.

When the pinned MOTIS image changes, regenerate these files from the matching MOTIS OpenAPI output. Keep application-specific routing state outside this package.
