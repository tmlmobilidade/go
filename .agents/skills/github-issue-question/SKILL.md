# Create question issue tickets

Use the shared process in [github-issues](../github-issues/references/workflow.md) and the [field catalog](../github-issues/references/issue-fields.md). This skill means the user has selected Question; if not, use the `github-issues` dispatcher first.

Clarify the exact question, why the answer is needed, relevant context, and who or what is affected. Investigate repository facts before asking the user. A Question issue records a question to be answered, so do not invent implementation tickets or acceptance criteria; state what a useful answer should resolve. Apply Modules only when repository evidence or the user establishes the domain.
