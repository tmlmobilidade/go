# What is this?
This file contains the font-face definitions for the fonts used in the UI.
It is a CSS file that defines the font-family, font-style, font-weight, and source of the fonts.
The fonts are embedded in the CSS file using base64 encoding.
This allows the fonts to be loaded directly from the CSS file without needing to load them from a separate file.
This is useful for performance reasons, as it reduces the number of HTTP requests needed to load the page.
It also ensures that the fonts are available even if the user is offline or if the font files are not available on the server.
